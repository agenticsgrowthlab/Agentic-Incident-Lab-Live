# ACH Settlement Window Matrix
Type: Rail document

Operational teams must evaluate the remaining processing window before selecting containment. When a settlement window remains open, stabilizing the system and reconciling unknown outcomes is safer than amplifying retries. As the window approaches closure, the incident commander must explicitly choose between controlled same-day recovery and deferral to the next eligible window.

A customer-visible delay is not automatically a settlement failure. Confirm acknowledgement, file acceptance, posting state, and return activity before describing the payment outcome.
